Problem statement

A CRM has the same customer entered multiple times with differently formatted emails. Remove duplicates where emails match after trimming spaces and ignoring case, keeping the first record.

Requirements

  • Create a normalised key with email.str.strip().str.lower().
  • Use drop_duplicates(subset=key, keep='first').
  • Rename ambiguous columns (e.g. nm to name) and print how many rows were removed.

Why clean the key first?

Computers compare text exactly. These three emails look different to Python, but they are the same person:

strip + lowerravi@x.com

strip() removes spaces at both ends. lower() makes all letters small. After this, equal emails become equal keys, so drop_duplicates can find them.
