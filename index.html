How the circular queue works

ISSUE

If size equals N the hall is full. Otherwise rear = (rear + 1) % N, and the first arrival sets front = rear = 0. The token number only increases on success.

SERVE

If size is 0 the queue is empty. Otherwise take the item at front, then front = (front + 1) % N. When the last person leaves, front and rear reset to -1.

Complexity

ISSUE and SERVE are O(1). SHOW is O(size). The array has fixed size N, so no space is wasted as seats are reused.
